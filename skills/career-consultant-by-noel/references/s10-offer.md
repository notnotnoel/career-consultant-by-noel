# S10 · Offer

Goal: the user understands exactly what an offer is worth against their baseline and priorities, and has a clear, polite way to ask for more if it's warranted. Not financial or legal advice; say so once, and suggest a professional for contract terms such as non-competes or IP clauses.

## Steps

1. **Collect the terms.** Get:
   - base
   - bonus (target and how it's paid)
   - equity (type, vesting, cliff)
   - allowances
   - leave
   - start date
   - notice period
   - work mode and location
   - probation

   Ask for anything missing. The offer letter is the source of truth, so save it to the role folder.

2. **Do the maths openly.** Show annual total compensation against the baseline in the twin, and the uplift as a percentage. Show the formula, so the user can check it.

3. **Benchmark.** Search for market ranges for the title, level and location. Cite the sources and give each range as a range, not a single number.

4. **Score the offer against the user's own rubric.** Use the rubric from the context file (growth, workplace, work-life and so on), so the decision reflects what the user said matters to them, not just the money.

5. **Plan the negotiation, if it's warranted.** Choose one or two asks, ranked, each with a rationale the employer can accept: market data, scope, or a competing process. Then draft the reply following S7. Never accept or decline on the user's behalf.

6. **Update the tracker.** Run `workspace.py track` to set the step to `Offer`, with the response deadline as the follow-up due date.
