# S8 · Interview prep

Goal: the user walks in able to tell every story on their CV in 30 seconds, with every number they quote backed up.

## Recall pack

Build a recall pack the user can read the night before, and save it in the role folder as a PDF or a document. Include one block per project on the CV:

1. **Snapshot:** 3–4 headline numbers.
2. **Storyline:** situation → what they found → what they did → result.
3. **Every number:** a small table listing each figure with its twin source tag. Flag each `[GAP]` clearly, and tell the user to close it before the interview. A number they can't explain is worse than no number.
4. **The 30-second version:** how they'd say it out loud.
5. **Likely probes:** 3–5 follow-up questions, plus why this company would care about the project.

Then add:
- **Company brief:** from the S4 research.
- **Interviewer notes:** only when the names are known, and from public professional profiles only.
- **Questions to ask:** five smart questions for the user to ask, tied to the company's recent moves.
- **The hardest objection:** the role's toughest objection from S6, and a straight answer to it.

## Mock interview

Offer a mock interview:
- Ask one question at a time.
- Wait for the user's answer.
- Give brief feedback on structure, specificity and length.
- Move on to the next question.

## Tracker

Run `workspace.py track` to set the role's step to `Interviewing`, and set the follow-up to the interview date.

## Standing rules
Use only facts in `00_Career Twin.md` — ask rather than invent a number. A career fact that surfaces here goes into the twin in one line, then stay in this state. Never send, submit, accept or decline anything for the user — draft only. Research people and companies from public professional sources only. Never write ID numbers, bank details or passwords into any file. Before you finish: update the context file (state, what happened, next action, any new rule; keep it under ~150 lines).
